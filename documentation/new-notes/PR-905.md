### RTEMS Initialization

GitHub [PR #905](https://github.com/epics-base/epics-base/pull/905)

This PR adds a new RTEMS Initialization to EPICS with aim of replacing
the existing POSIX implementation. It resolves a number of important
issues with the existing implementation.

1. Move BSP specific code that relies on hidden or undocumented RTEMS
   BSP interfaces into RTEMS
1. Depend on supported RTEMS interfaces avoiding code, variables or
   defines in RTEMS that can change
1. Provide a way for an IOC to add new initialization steps without
   needing to change and rebuild EPICS
1. A small design using standard C++

This initialization has been tested with RTEMS 7 with LibBSD
`7-freebsd-14` and RTEMS 6 with LibBSD `6-freebsd-14`.

[RTEMS Initialize](epicsRtemsInit.md) contains the details for use.
