### Base's `FINAL_LOCATION` setting no longer leaks into other modules

GitHub [PR #1043](https://github.com/epics-base/epics-base/pull/1043)

If `FINAL_LOCATION` was set in Base's `configure/CONFIG_SITE`
(or another of Base's site configuration files),
that setting was installed with Base
and applied to every module built against that installation
that did not set its own `FINAL_LOCATION`.
The library paths embedded in such a module's executables and libraries
then pointed into Base's final location instead of the module's own,
so they could not find the module's shared libraries at runtime.

Now a `FINAL_LOCATION` setting from Base only applies to modules
that install into Base (such as the bundled PVA submodules).
Other modules get the default
(the absolute path of their own `INSTALL_LOCATION`)
unless they set `FINAL_LOCATION` themselves.
