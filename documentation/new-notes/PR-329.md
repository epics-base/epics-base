### Support for the 64-bit LoongArch (`linux-loong64`) CPU architecture

GitHub [PR #329](https://github.com/epics-base/epics-base/pull/329)

EPICS Base can now be built for 64-bit LoongArch (Loongson) processors,
using the target architecture name `linux-loong64`
and the GNU toolchain triplet `loongarch64-linux-gnu`.
[LoongArch](https://loongson.github.io/LoongArch-Documentation/)
is a RISC-style instruction set architecture developed by Loongson Technology,
used by their 3A5000/3A6000 and 2K series processors;
see that page for the architecture specification,
and the Linux kernel documentation
for [an introduction to LoongArch](https://docs.kernel.org/arch/loongarch/introduction.html).

Both native and cross builds are supported:

 * On a LoongArch64 Linux machine `EpicsHostArch.pl` reports
   `linux-loong64` as the host architecture,
   so a plain `make` builds Base for that machine.

 * When building from a linux-x86_64 host,
   set `CROSS_COMPILER_TARGET_ARCHS = linux-loong64` in `configure/CONFIG_SITE`
   and point `GNU_DIR` at a `loongarch64-linux-gnu` cross toolchain
   (`GNU_TARGET` only has to be changed if the toolchain uses another prefix).

Both "old world" (ABI 1.0, glibc 2.27 based, as used by Loongnix and UOS)
and "new world" (ABI 2.0, as used by Debian 13 and recent Ubuntu releases)
LoongArch64 toolchains can be used;
they share the `loongarch64-linux-gnu-` tool prefix,
so selecting one or the other is only a matter of setting `GNU_DIR`.
See [the LoongArch old world/new world notes](https://areweloongyet.com/en/docs/world-compat-details/)
for the background.

No architecture-specific compiler options are added by default,
so the compiler's generic LoongArch64 baseline
and its default `lp64d` ABI are used.
Sites that need a different cpu-type
or a different ABI/FPU setting
can set `ARCH_DEP_CFLAGS`
in `configure/os/CONFIG_SITE.Common.linux-loong64`.
