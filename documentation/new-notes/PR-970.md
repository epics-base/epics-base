### Add support for building on MVME5100 with RTEMS

RTEMS 7 added support for MVME5100 BSP, and the RTEMS port
has been tested with EPICS 7

[This PR](https://github.com/epics-base/epics-base/pull/970)
adds the required configure file modifications to enable building
epics-base for mvme5100 target on RTEMS
