### CA client no longer delays channels found while a circuit shuts down

GitHub [PR #1004](https://github.com/epics-base/epics-base/pull/1004)

When a client cleared its last channel to a server
and then created another channel on the same server,
the search reply could arrive while the old circuit was still shutting down.
The new channel was then installed on that closing circuit,
disconnected with it,
and searched for again only 10 seconds later,
so `ca_pend_io()` for it could time out.
The client now opens a new circuit to the server for such a channel,
which connects at once.
