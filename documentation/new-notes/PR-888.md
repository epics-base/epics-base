### Support for Windows on 64-bit ARM processors

Add new host architectures windows-aarch64, windows-aarch64-static
and windows-aarch64-debug and fix CPU dependencies for Windows.

Even though Visual Studio calls the 64 bit ARM architecture "arm64",
the corresponding EPICS host architecture is "windows-aarch64" to
maintain naming consistency with linux-aarch64 host architectures.

The startup/windows.bat file now accepts an optional argument to
set up Visual Studio with a different than then native processor
architecture, .e.g. x64 on arm64.

The location of Visual Studio is now found automatically if not
set by the user.
