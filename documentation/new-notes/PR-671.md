### Call exit handlers on SIGTERM and SIGINT

On Linux and MacOS systems, attempt to run exit handlers
installed with `epicsAtExit` even if the IOC received
`SIGINT` (Ctrl-C) or `SIGTERM` (what wrappers like procServ
usually send to kill an IOC).

On the same architectures, a timeout can be set for running the
exit handlers. Set the environment variable `EPICS_EXIT_TIMEOUT`
to a positive number of seconds. If the timeout expires before
all exit handlers complete, the process is killed.
