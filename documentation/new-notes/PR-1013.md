### Filter Channel Access client reports with `casmatch`

GitHub [PR #1013](https://github.com/epics-base/epics-base/pull/1013)

The new IOC shell command `casmatch` reports connected TCP Channel Access
clients whose channel names match a case-sensitive glob pattern.
The pattern supports `*` for zero or more characters and `?` for one character.
Clients without matching channels are omitted.

The optional report level follows the client-report detail levels used by
`casr`, from a summary at level 0 through channel, connection, memory, and lock
diagnostics at higher levels.

For example, this lists the clients connected to channels under the `DEV:`
prefix and prints the matching channel names:

```iocsh
casmatch "DEV:*" 2
```
