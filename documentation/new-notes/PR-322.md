### IOC shell tab completion of record field names

GitHub [issue #322](https://github.com/epics-base/epics-base/issues/322)

The GNU readline tab completion of record name arguments in the IOC shell
(added in 7.0.8) now also completes field names.
Once the record name is followed by a `.`, pressing tab suggests
the fields of that record which match what has been typed so far:

```
epics> dbpf CA_TESTS:SEQ.D<tab>
CA_TESTS:SEQ.DESC  CA_TESTS:SEQ.DISA  CA_TESTS:SEQ.DISP  CA_TESTS:SEQ.DISS
CA_TESTS:SEQ.DISV  CA_TESTS:SEQ.DPVT  CA_TESTS:SEQ.DSET  CA_TESTS:SEQ.DTYP
epics> dbpf CA_TESTS:SEQ.DE<tab>
epics> dbpf CA_TESTS:SEQ.DESC
```

Record aliases may be used before the `.`.
No suggestions are offered when the record name doesn't exist,
instead of the misleading partial record name shown previously.
