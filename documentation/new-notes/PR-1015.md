### Added and used EPICS_FALLTHROUGH macro

GitHub [PR #1015](https://github.com/epics-base/epics-base/pull/1015)

In many places in the epics-base, there were comments denoted fallthroughs.
Starting in C++17, an attribute was defined so that intentional fallthroughs would not generate a compiler warning.
This change defines a macro EPICS_FALLTHROUGH and applies it in the previously commented fallthroughs.
