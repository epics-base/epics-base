### Fix `-rpath` when `FINAL_LOCATION` is used and `LINKER_USE_RPATH=YES`

When building with `LINKER_USE_RPATH=YES`, the linker option `-rpath` has
been corrected to receive a path based on `FINAL_LOCATION` rather than
`INSTALL_LOCATION` to allow finding libraries at run-time.

In addition, `-rpath-link` is passed to the linker with a path based on
`INSTALL_LOCATION` in order to find libraries at build-time.

`LD_LIBRARY_PATH` is set during the build to allow tools to find their
libraries in `INSTALL_LOCATION`.
